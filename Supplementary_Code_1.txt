Supplementary Code 1. Colocalization analysis of NDUFB3 cis-eQTL
and early AMD GWAS.

This document describes the complete workflow for colocalization analysis
between NDUFB3 cis-eQTL (GTEx v6p, Adipose_Subcutaneous and Whole_Blood)
and early AMD GWAS (GCST010723). All steps are reproducible from public
data resources.

================================================================
Step 2. Liftover GRCh37 → GRCh38
================================================================

Tool: Python liftover package (v1.5.0)
Install: pip install liftover

Python code (scripts/07_7f_coloc_NDUFB3.py):
--------------------------------------------------------------
import pandas as pd
from liftover import get_lifter

df = pd.read_csv("E:/retina_tools/aging_rgc_axon/AMD/results/07_7f_coloc_NDUFB3/ndufb3_gwas_region.csv")

converter = get_lifter('hg19', 'hg38', one_based=True)

hg38_pos = []
for _, row in df.iterrows():
    chrom = str(int(row['chr']))
    pos = int(row['pos'])
    result = converter[chrom][pos]
    if result:
        hg38_pos.append(result[0][1])
    else:
        hg38_pos.append(None)

df['pos_hg38'] = hg38_pos
df_hg38 = df.dropna(subset=['pos_hg38'])

colstats = df_hg38[['chr', 'pos_hg38', 'ES', 'SE']].copy()
colstats.columns = ['chrom', 'pos', 'beta', 'se']
colstats.to_csv("E:/retina_tools/aging_rgc_axon/AMD/results/07_7f_coloc_NDUFB3/NDUFB3_earlyAMD_COLSTATS_hg38.tsv",
                sep='\t', index=False)
--------------------------------------------------------------

Output: NDUFB3_earlyAMD_COLSTATS_hg38.tsv
Columns: chrom, pos, beta, se (GRCh38)

Step 3. Colocalization analysis (COLSTATS v2.3)
================================================================

Platform: COLSTATS v2.3 (https://colstats.irgb.cnr.it)
Mode: Targeted

Trait 1: early AMD (GCST010723) — uploaded file
Trait 2: NDUFB3 cis-eQTL — from COLSTATS database
  - Adipose_Subcutaneous: cs_4612_c (GTEx v6p, n = 581)
  - Whole_Blood: cs_1067364_c (GTEx v6p, n = 670)

Region: 2:201120000-203133000 (GRCh38, 2013 kb)
Priors: p_h1 = 1e-4, p_h2 = 1e-4, p_h12 = 1e-5
LD reference: 1000 Genomes Project phase 3, EUR

Raw COLSTATS output: reproducibility/07_7f_coloc_NDUFB3/NDUFB3_colstats.txt
Web-session screenshots: reproducibility/07_7f_coloc_NDUFB3/figure/
